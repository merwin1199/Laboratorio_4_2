Estudiante:
Merwin Arciniegas Remolina

Descripción:
En este proyecto se creó una página web utilizando HTML5 y CSS.
La actividad permite practicar la estructura semántica de HTML y
diferentes técnicas de diseño mediante CSS.

Elementos utilizados:
- HTML5 para crear la estructura de la página.
- CSS para aplicar estilos y organizar el contenido.
- Selectores de elementos, clases e IDs.
- Propiedades CSS para colores, tamaños, márgenes y bordes.
- Modelo de caja utilizando margin, border, padding y contenido.
- Diseño responsivo mediante media queries.
- Imagen en formato SVG.
- Git y GitHub para guardar el proyecto.

Características principales de HTML5:
La página utiliza elementos semánticos como header, nav, main,
section, article y footer. Estos elementos permiten organizar
el contenido de una forma clara y estructurada.

Características de CSS:
Se utilizaron diferentes tipos de selectores para aplicar estilos
de manera específica. También se utilizó el modelo de caja y una
media query para adaptar la página a pantallas pequeñas.
